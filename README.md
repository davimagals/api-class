# api-class

API criada para ensino de programação WEB e Mobile Híbrida no curso técnico em Desenvolvimento de Sistemas de uma Escola Profissional do Estado do Ceará.

Oferece algumas rotas para diferentes contextos para diferentes exercícios.

# Comandos

- Subir:
  docker compose up -d

- Rebuilda o projeto:
  docker compose up --build -d

- Reset total (recria banco):
  docker compose down -v
  docker compose up -d
