Documentação da API — Sistema de Multas

Base URL

https://ubuntu-server.tail562deb.ts.net

Endpoints

Health Check

Verifica se a API está online.

Request

GET /health

Response

{
  "status": "ok"
}

Motoristas

Listar Motoristas

Retorna todos os motoristas cadastrados.

Request

GET /api/motoristas

Response

[
  {
    "cnh": "793242826",
    "nome": "João Silva",
    "data_nascimento": "1990-01-01",
    "endereco_id": 1
  }
]

Buscar Motorista por CNH

Retorna um motorista específico.

Request

GET /api/motoristas/:cnh

Exemplo

GET /api/motoristas/793242826

Response

{
  "cnh": "793242826",
  "nome": "João Silva",
  "data_nascimento": "1990-01-01",
  "endereco_id": 1
}

Response — Não encontrado

{
  "success": false,
  "message": "Motorista não encontrado"
}

Criar Motorista

Cria um motorista e um endereço associado.

Request

POST /api/motoristas
Content-Type: application/json

Body

{
  "cnh": "123456789",
  "nome": "Maria Oliveira",
  "data_nascimento": "1995-06-15",
  "rua": "Rua das Flores",
  "numero": 100,
  "complemento": "Apto 202",
  "bairro": "Centro",
  "cidade": "Fortaleza",
  "estado_id": 6
}

Response

{
  "data": {
    "id": 4,
    "cnh": "123456789",
    "nome": "Maria Oliveira",
    "data_nascimento": "1995-06-15",
    "rua": "Rua das Flores",
    "numero": 100,
    "complemento": "Apto 202",
    "bairro": "Centro",
    "cidade": "Fortaleza",
    "estado_id": 6
  }
}

Atualizar Motorista

Atualiza os dados do motorista e endereço.

Request

PUT /api/motoristas/:cnh
Content-Type: application/json

Exemplo

PUT /api/motoristas/123456789

Body

{
  "nome": "Maria Oliveira Santos",
  "data_nascimento": "1995-06-15",
  "endereco_id": 4,
  "rua": "Rua Nova",
  "numero": 150,
  "complemento": "Casa",
  "bairro": "Centro",
  "cidade": "Fortaleza",
  "estado_id": 6
}

{
  "data": {
    "cnh": "123456789",
    "nome": "Maria Oliveira Santos",
    "data_nascimento": "1995-06-15",

Validação

A API utiliza validação com Zod.

Exemplo de erro de validação

{
  "success": false,
  "message": "Validation error",
  "details": [
    {
      "path": ["nome"],
      "message": "String must contain at least 3 character(s)"
    }
  ]
}

Status Codes

Código Descrição
200 Sucesso
201 Recurso criado
400 Erro de validação
404 Recurso não encontrado
500 Erro interno do servidor

Observações

  • Todas as requisições e respostas utilizam JSON.
  • Datas utilizam o formato YYYY-MM-DD.
  • A API possui CORS liberado temporariamente.
  • O endpoint público utiliza HTTPS.
